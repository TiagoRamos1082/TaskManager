# Entidades

## Tarefa

A entidade `Tarefa` representa uma atividade que precisa ser realizada pelo usuário.

### Atributos

* `title`: título ou descrição da tarefa;
* `completed`: indica se a tarefa foi concluída.

### Exemplo

```text
Título: Estudar PHP
Concluída: Não
```

Uma tarefa pode assumir dois estados:

* Pendente;
* Concluída.
